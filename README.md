# My Developer Portfolio 🌐

This is my personal developer portfolio built using **React + Vite** and styled with **Tailwind CSS**. It showcases my skills, projects, certifications, and includes a dark mode toggle and smooth animations.

## 🚀 Features

- React 18 + Vite
- Tailwind CSS for styling
- Responsive layout
- Dark mode toggle with animation & sound
- Project image gallery
- Downloadable resume
- Smooth scrolling navigation
